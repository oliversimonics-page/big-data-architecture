# Indító scriptek

Windows PowerShell:
`.\scripts\lesson-01-start.ps1`

Windows CMD:
`.\scripts\lesson-01-start.cmd`

Linux/macOS:
`./scripts/lesson-01-start.sh`

PowerShell esetén, ha a gépen tiltott a saját szkriptek futtatása:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

Ez csak az aktuális felhasználó PowerShell script futtatási szabályát állítja át.
